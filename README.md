# Student Management System
A complete student database system with add, view, search, update, delete, and statistics features. Built with Python dictionaries, lists, loops, and functions.
A command-line Python application to manage student records. Perfect for small classes or training centers.

## Features

- **➕ Add Student**: Record name, age, course, and grade.
- **📋 View All**: Display all student records in a formatted table.
- **🔍 Search**: Find students by ID or name.
- **✏️ Update**: Modify a student's grade.
- **🗑️ Delete**: Remove a student record.
- **📊 Statistics**: View class average, highest/lowest scores, and grade distribution.
- **💾 Save Data**: Export all records to a `.txt` file.

## Technologies Used

- **Language**: Python 3
- **Concepts Demonstrated**:
    - Variables & Data Types
    - Control Flow (`if`, `elif`, `else`)
    - Loops (`for`, `while`)
    - Data Structures (Lists, Dictionaries)
    - Functions
    - File I/O (`open`, `write`)

## How to Run

1.  **Option A (Run Online)**: Open the `Student_Management_System.ipynb` file in this repository using Google Colab.
2.  **Option B (Run Locally)**:
    - Ensure you have Python 3 installed.
    - Save the code from the `.ipynb` file into a `.py` file.
    - Run `python your_filename.py` in your terminal.
